Yousign Connector

This module connects Odoo and Yousign via the Yousign API v3. It allows to easily create a signature request from any Odoo object (quotation, contract, …). You can define signature templates (like email templates) to make it easier to create signature requests.

When all the signatories have signed, the signed PDF files are automatically downloaded and attached to the source object, either in real time via the Yousign webhook or via a scheduled action.

Installation

To install this module, you need several Python libraries:

  • requests
  • pypdf (version 3.1.0 or higher)
  • unidecode

The installation of the OCA module partner_firstname is recommended, but not required.

Configuration

You must edit the Odoo server configuration file and add the following keys:

  • yousign_apikey: Yousign API key
  • running_env: prod to use the production API (https://api.yousign.app/v3); any other value uses the sandbox API (https://api-sandbox.yousign.app/v3)
  • yousign_secret: secret key of the Yousign webhook (only required if you use the webhook)

Then restart the Odoo server with the updated configuration file.

Webhook (optional, recommended)

To get the signed documents in real time, create a webhook in the Yousign application (Developers > Webhooks) with the following URL:

https://<your-odoo-domain>/<database-name>/yousign/webhook

and subscribe to the events signature_request.done, signature_request.declined, signature_request.expired, signer.done and signer.declined. Copy the secret key generated by Yousign into the yousign_secret key of the Odoo server configuration file.

Each webhook call is authenticated by checking its HMAC-SHA256 signature (header X-Yousign-Signature-256) with this secret: calls with a missing or wrong signature are rejected. Processing is idempotent, so an event delivered several times by Yousign is only processed once.

If the Odoo server hosts several databases, the database of the URL must also be selected by the dbfilter option of the server, otherwise the webhook URL returns a 404 error.

Usage

The Yousign signature request templates are available in the menu Settings > Technical > Yousign > Request Templates. Once you have finished the configuration of a Yousign request template, you can click on the button Add Action at the top right corner to add an entry in the Action menu of the object.

If you prefer to have a directly accessible button on the form view of the object to initiate the Yousign request instead of using the entry in the Action menu, you should inherit the form view of that object and add a button like below:

<button name="%(yousign_connector.new_yousign_request_action)d" type="action" string="Send Yousign Request" context="{'yousign_template_xmlid': 'yousign_sale.sale_sign_template'}"/>

The link to the Yousign template is given by the context:

  • either by giving the XMLID of the Yousign request template: {'yousign_template_xmlid': 'yousign_sale.sale_sign_template'}
  • or by giving the ID of the Yousign request template: {'yousign_template_id': 42}

The Yousign signature requests are available in the menu Settings > Technical > Yousign > Signature Requests.

In the menu Settings > Technical > Automation > Scheduled Actions, you will find a scheduled action called Yousign Requests Update, inactive by default. It updates the status of the Yousign requests with pending signature and downloads the signed files of the Yousign requests that are signed by all signatories. Activate it if you don’t use the webhook, or as a fallback.

In the sandbox environment, the email of the signatories must belong to your Yousign organization and the SMS one-time password is always 123456.
