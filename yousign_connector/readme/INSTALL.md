To install this module, you need several Python libraries:

- [requests](https://pypi.org/project/requests/)
- [pypdf](https://pypi.org/project/pypdf/) (version 3.1.0 or higher)
- [unidecode](https://pypi.org/project/Unidecode/)

The installation of the OCA module
[partner_firstname](https://github.com/OCA/partner-contact/tree/18.0/partner_firstname)
is recommended, but not required.
