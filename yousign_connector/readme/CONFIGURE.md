You must edit the Odoo server configuration file and add the following keys:

- `yousign_apikey`: Yousign API key
- `running_env`: `prod` to use the production API
  (`https://api.yousign.app/v3`); any other value uses the sandbox API
  (`https://api-sandbox.yousign.app/v3`)
- `yousign_secret`: secret key of the Yousign webhook (only required if you
  use the webhook)

Then restart the Odoo server with the updated configuration file.

**Webhook (optional, recommended)**

To get the signed documents in real time, create a webhook in the Yousign
application (*Developers > Webhooks*) with the following URL:

    https://<your-odoo-domain>/<database-name>/yousign/webhook

and subscribe to the events `signature_request.done`,
`signature_request.declined`, `signature_request.expired`, `signer.done` and
`signer.declined`. Copy the secret key generated by Yousign into the
`yousign_secret` key of the Odoo server configuration file.

Each webhook call is authenticated by checking its HMAC-SHA256 signature
(header `X-Yousign-Signature-256`) with this secret: calls with a missing or
wrong signature are rejected. Processing is idempotent, so an event delivered
several times by Yousign is only processed once.

If the Odoo server hosts several databases, the database of the URL must also
be selected by the `dbfilter` option of the server, otherwise the webhook URL
returns a 404 error.
